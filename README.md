# Qclod

## Что это

Окно для Claude Code на Windows и на Mac с чипом Apple (M1 и новее). Нужна подписка Claude (Pro или Max) или ключ API.

## Как поставить на Windows

Скачайте `Qclod-X.Y.Z-setup.exe` со страницы релизов: https://github.com/SOJuse/qclod/releases/latest. Запустите файл и пройдите мастер установки.

При запуске установщика Windows может написать «Windows защитил ваш компьютер». Нажмите «Подробнее», затем «Выполнить в любом случае».

Почему так: у установщика нет платной подписи. Файл собирается на GitHub из этого репозитория.

## Qclod на Mac

Нужен Mac с чипом Apple (M1 и новее) и macOS 11 и новее.

1. Скачайте `Qclod-<версия>-arm64.dmg`, откройте его и перетащите Qclod в «Программы».
2. При первом запуске macOS скажет, что не может проверить приложение. Нажмите «Готово».
3. Откройте «Системные настройки» → «Конфиденциальность и безопасность», внизу у строки про Qclod нажмите «Открыть всё равно» и подтвердите паролем. Кнопка видна около часа после попытки запуска.
4. Если macOS пишет, что Qclod «повреждён»: `xattr -dr com.apple.quarantine /Applications/Qclod.app`.
5. После обновления macOS может один раз спросить доступ к связке ключей — там лежат сохранённые пароли серверов.

Почему так: у приложения нет подписи Apple, оно подписано только локально (ad-hoc). Сборка идёт на GitHub из этого репозитория.

## Первый запуск

На первом экране нажмите «Установить» — Qclod поставит Claude Code. Потом нажмите «Войти»: откроется окно, а в нём браузер. Когда вы войдёте, Qclod заметит это сам. Останется нажать «Начать работу».

Если установка не получилась, нажмите «Попробовать снова». Если и так не выходит, нажмите «Открыть настройки» и укажите путь к `claude.exe` (на Mac — к `claude`). На Mac Qclod берёт PATH из вашей оболочки входа и находит `claude`, поставленный из терминала.

## Проекты и чаты

Слева — проекты и их чаты. Чаты можно открыть рядом: до четырёх в сплите. Ctrl+K (на Mac — Cmd+K) ищет по всему сразу: чаты, проекты, прошлые разговоры (и по их тексту), файлы, шаблоны, действия.

## Сообщения во время работы

Пока агент работает, новые сообщения встают в очередь над полем ввода. У каждого — «Отправить сейчас», «Изменить» и «Убрать из очереди».

## Агент без вас

- «Авто-да» — Qclod сам отвечает «разрешить» на запросы агента. В настройках задаётся, через сколько минут Qclod сам ответит на вопрос или одобрит план, если вы не ответили.
- Если агент упал или упёрся в лимит, Qclod продолжит работу сам, когда это станет возможно.
- Пока агент работает, компьютер не засыпает сам. Закрытая крышка ноутбука, кнопка питания и «Сон» всё равно его усыпят — работа встанет до пробуждения. Чтобы агент работал при закрытом компьютере, запускайте его на сервере (см. «Серверы по SSH»).
- Remote Control — продолжить сессию с телефона или claude.ai.

## Сабагенты

Кнопка «Агенты» в заголовке чата показывает фоновых агентов: граф или хронологию, ленту каждого. Агенту можно написать или остановить его.

«Стоп» прерывает ход главного агента, фоновые агенты при этом работают дальше. Остановить их — «Остановить» у агента или «Остановить все» в диспетчере задач («Фоновые»).

## Голосовой ввод

Только на Windows, на Mac голоса пока нет.

- Скачайте модель в настройках «Голос». По умолчанию — GigaAM v3. Whisper — точнее с английскими терминами (нужна видеокарта NVIDIA и Microsoft Visual C++ Runtime; если его нет, Qclod даст ссылку).
- Ctrl+Пробел: удерживайте и говорите — или нажмите один раз, чтобы начать, и ещё раз, чтобы закончить. То же умеет кнопка с микрофоном в поле ввода.
- Голос только вставляет текст в поле. Отправляете вы.

## Серверы по SSH

- Сервер добавляется из `~/.ssh/config` или вручную: «Новый чат на сервере» или настройки «Серверы». Вход по ключу или по паролю; пароль хранится в системном хранилище.
- При первом подключении Qclod покажет отпечаток ключа сервера. Если отпечаток потом сменится, Qclod не подключится и скажет, что проверить.
- Qclod ставит на сервер посредника в `~/.qclod/`. Агент работает в нём, даже когда ваш компьютер закрыт; при новом подключении чат продолжится с того же места. Чтобы посредник жил и после выхода из ssh, выполните на сервере один раз `sudo loginctl enable-linger <пользователь>` — Qclod подскажет.
- Claude Code на сервере ставите вы сами. Войти в него можно из Qclod: «Войти» в панели серверного чата, затем ссылка и код.
- Файлы сервера открываются в просмотрщике, @-упоминания ищут по файлам сервера, вложения загружаются на сервер. Кнопка «Терминал» в заголовке чата открывает терминал сервера.

## Шаблоны

Шаблон — готовый текст сообщения. Вставляется из списка «/» в поле ввода или из Ctrl+K; создать, изменить и удалить — «Шаблоны» в Ctrl+K, черновик можно сохранить как шаблон.

«Собрать мои шаблоны»: Qclod читает только ваши собственные сообщения из истории Claude Code, отправляет их одним запросом в Claude через ваш Claude Code и предлагает шаблоны. Сами сообщения не сохраняются — только шаблоны, которые вы отметите.

## Git

Кнопка «Git» в заголовке чата показывает изменения в папке проекта: список файлов, diff, коммит отмеченных файлов. Работает и для проектов на сервере (нужен посредник Qclod 1.0 — иначе Qclod попросит его обновить).

Веток, слияний, push и pull в Git-панели нет: это — в терминале или через агента.

## Режимы разрешений

Режим выбирается в строке под полем ввода:

- «спрашивать» — агент спрашивает про каждое действие;
- «принимать правки» — правки файлов без вопросов, команды — с вопросом;
- «план» — только читает и предлагает план;
- «авто-да» — агент спрашивает, а Qclod сам отвечает «разрешить». Сохранённые запреты действуют, вопросы и планы остаются за вами;
- «классификатор» — решает модель Claude Code, если не уверена — спрашивает;
- «только разрешённое» — всё, что не разрешено заранее, запрещено;
- «без проверок» — после подтверждения агент ничего не спрашивает.

## Ответы на запросы агента

- Запрет можно объяснить: причину агент прочитает вместе с запретом.
- «Разрешить до конца сессии» действует только в этом чате и только пока работает его агент: до «Начать заново», закрытия чата, перезапуска после сбоя или выхода из Qclod. На диск такое разрешение не пишется.
- План можно отклонить с комментарием или поправить перед одобрением — агент выполнит поправленный план.
- К выбранному варианту ответа на вопрос можно добавить комментарий.

## Команды только для терминала

Некоторые команды Claude Code (например, `/chrome`) работают только в терминале. Qclod скажет об этом и предложит кнопку «Открыть терминал»: откроется Claude Code в папке вкладки.

## Обновления

- Windows: установленный Qclod скачивает новые версии сам и предлагает перезапуститься.
- Mac: Qclod покажет «Вышла версия…» со ссылкой на DMG; поставить — как в первый раз.
- Портативный `Qclod.exe` сам не обновляется: скачайте его заново со страницы релизов.

## Известные ограничения

- Qclod для Linux нет; сервером может быть Linux x64 или arm64.
- Голосового ввода на Mac нет.
- У прошлых разговоров на сервере нет графа сабагентов — он есть у живых серверных чатов.
- Нет подписи ни у установщика Windows, ни у приложения на Mac.

## Как удалить

- Windows: «Параметры → Приложения», найти Qclod и удалить.
- Mac: перетащить Qclod из «Программ» в корзину; данные Qclod — в `~/Library/Application Support/Qclod`.

Переписки остаются в Claude Code, Qclod их не хранит. Посредник на сервере удаляется вместе с папкой `~/.qclod/`.

## Для разработки

```
npm ci
npm run dev
npm run dist        # Windows: установщик и портативный exe
npm run dist:mac    # Mac: DMG arm64 (на Mac)
```

Выпуск: поднять `version` в `package.json`, сделать коммит, затем

```
git tag vX.Y.Z
git push --tags
```

Сборку и публикацию делает workflow `.github/workflows/release.yml`: посредник для серверов (`qclod-relay`, Linux x64 и arm64), затем Windows, затем Mac. Посредник кладётся в релиз раньше установщика.

Сборка до тега (push в `release/**` или `ci/**`) ничего не публикует: установщики и `.gz` посредника лежат в артефактах прогона. Чтобы такая сборка поставила посредник на сервер, положите файлы `qclod-relay-<версия>-linux-x64.gz` и `-arm64.gz` из артефактов в папку `relay` данных Qclod (`%APPDATA%\Qclod\relay\`, на Mac — `~/Library/Application Support/Qclod/relay/`): файл берётся оттуда, если его SHA-256 совпадает с манифестом сборки.
