# Qclod 1.0.1

## Что нового в 1.0.1
- **VPN для Claude.** Встроенный клиент Hysteria2: через туннель идёт только Claude Code (и сайты из списка через системный PAC), остальная система — напрямую. Значок слева внизу, раздел настроек «VPN», автоподключение. Если туннель не поднялся, Claude не уходит в сеть напрямую.
- **Терминал в каждом чате.** Кнопка «Терминал» теперь и у обычных чатов: PowerShell на Windows, ваша оболочка на Mac, в папке чата.
- **Стрелки в поле ввода.** ↓ после ↑ идёт по строкам вызванного сообщения (и по перенесённым строкам), черновик не пропадает после прогулки по истории — возвращается вместе с кареткой.

# Qclod 1.0.0

## Этап 1 — стабильность и очередь
Окно не сереет и не зависает на длинной вставке, сбой одной панели не роняет остальные. Сообщения, написанные во время работы агента, встают в очередь: «Отправить сейчас», «Изменить», «Убрать из очереди».

## Этап 2 — облик, проекты и сплит
Новый облик, боковая панель с проектами и чатами, сплит до четырёх чатов, Ctrl+K — поиск по чатам, проектам, прошлым разговорам, файлам и действиям. Настройки собраны по разделам.

## Этап 3 — агент без вас
«Авто-да» и авто-ответ на вопросы и планы через заданное число минут, продолжение работы после падения и после лимита, запуск при входе в систему, Remote Control, «не спать» на время работы.

## Этап 4 — сабагенты
Кнопка «Агенты» над лентой: граф и хронология фоновых агентов, лента каждого, написать агенту или остановить его.

## Этап 5 — голосовой ввод
Локальное распознавание речи: GigaAM v3 по умолчанию, Parakeet v3, Whisper для NVIDIA. Ctrl+Пробел — удерживать и говорить или нажать один раз. Голос только вставляет текст в поле.

## Этап 6 — Mac и серверы по SSH
Qclod для Mac на Apple Silicon (DMG arm64). Серверы по SSH: посредник на сервере держит работу агента, пока компьютер закрыт; файлы сервера в просмотрщике, @-упоминания и вложения, терминал сервера, вход в Claude Code на сервере из Qclod.

## Этап 7 — шаблоны, Git, поиск по истории
Шаблоны сообщений в «/» и Ctrl+K, «Собрать мои шаблоны» из своих прошлых сообщений. Git-панель: изменения, diff, коммит отмеченных файлов — и для серверных проектов. Полнотекстовый поиск по прошлым разговорам в Ctrl+K.

## Что не вошло
- Linux-версия Qclod.
- Голосовой ввод на Mac.
- Автообновление на Mac: Qclod сообщает о новой версии ссылкой.
- Подпись установщика и приложения (Windows и Apple).
- Граф сабагентов у прошлых разговоров на сервере: живые серверные чаты его показывают.
