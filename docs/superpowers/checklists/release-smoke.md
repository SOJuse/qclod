# Релизный чек-лист Qclod

Автотесты гоняются только против подставного агента — так они детерминированы,
не требуют аккаунта и не тратят токены. Этот список закрывает то, что они
принципиально проверить не могут: поведение **настоящего** Claude Code CLI и
вещи уровня операционной системы.

Прогоняется один раз перед выпуском установщика.

```
npm run test:unit        # должно быть зелено
npm run test:e2e         # должно быть зелено
npm run dist             # собирает dist/Qclod-<версия>-setup.exe
QCLOD_PACKAGED_EXE=dist/win-unpacked/Qclod.exe npx playwright test packaged
```

Затем поставить установщик на чистую папку и пройти список руками.

## Против настоящего CLI

- [ ] **Запуск.** Приложение открывается, вкладка поднимается, виден привет
      Claude Code. Если папка новая — CLI спросит о доверии к ней; на вопрос
      можно ответить стрелками и Enter прямо в терминале.
- [ ] **Обычный запрос.** Написать что-нибудь в поле ввода, Enter. Запрос
      уходит целиком, ответ печатается.
- [ ] **Многострочная вставка.** Скопировать 3–4 строки откуда угодно, Ctrl+V
      в поле ввода, Enter. Агент получает **один** запрос, а не три.
      *(Не покрыто автотестами против настоящего CLI — проба 2 из
      `docs/superpowers/notes/2026-11-07-probe-results.md`.)*
- [ ] **Слэш-команда.** Набрать `/` — появляется индикатор проброса и родное
      меню команд CLI со всеми вашими и плагинными командами. Стрелки двигают
      выбор, Enter выполняет.
- [ ] **Меню разрешения.** Попросить агента изменить файл. Когда он спросит
      разрешение, фокус уходит в терминал и на вопрос можно ответить стрелками
      и Enter.
- [ ] **Прерывание.** Во время работы агента нажать Esc — работа прерывается,
      даже если в поле ввода набран текст.
- [ ] **Хуки и индикатор.** Точка на вкладке: синяя пульсирует пока агент
      работает, зелёная когда закончил, жёлтая когда ждёт ответа. Полая точка
      означает, что хуки не дошли и состояние угадано — этого быть не должно.
      *(Проба 4: доставка хуков через `--settings` подтверждена только против
      подставного агента.)*
- [ ] **Чужие хуки целы.** Если в `~/.claude/settings.json` есть свои хуки —
      убедиться, что они по-прежнему срабатывают в сессии внутри Qclod.
- [ ] **Картинка.** Сделать скриншот (Win+Shift+S), Ctrl+V в поле ввода.
      Подставляется `@путь`, и агент действительно видит изображение.
- [ ] **Перетаскивание.** Перетащить в окно файл и папку, в том числе из пути
      с пробелами и кириллицей. Пути вставляются целиком и агент их открывает.
- [ ] **@-упоминание.** Набрать `@`, выбрать файл — агент его читает.
- [ ] **Путь в кавычках.** ВАЖНО, проверить первым: выбрать через `@` файл из папки
      с пробелом в имени. Qclod подставляет `@"путь с пробелом"`, и это
      единственное место, где соглашение о кавычках не подтверждено ничем, кроме
      наших же тестов. От него зависят и перетаскивание, и вставка картинок —
      у кого в имени пользователя есть пробел, туда попадает каждый скриншот.
      Если CLI кавычки не понимает, чинить надо `quotePath` в
      `src/renderer/input/mentions.ts`.

## Уровень операционной системы

- [ ] **Глобальный хоткей.** Свернуть окно, из другого приложения нажать
      Ctrl+Shift+Space — окно всплывает поверх всего. Ещё раз — прячется.
- [ ] **Занятый хоткей.** Назначить в настройках комбинацию, которую уже
      держит другое приложение. В настройках появляется предупреждение с
      названием комбинации.
- [ ] **Трей.** Закрыть окно крестиком — приложение сворачивается в трей, а не
      завершается. Меню трея показывает вкладки и открывает нужную.
- [ ] **Уведомление.** Уйти в другое окно, дождаться окончания работы агента —
      приходит системное уведомление со звуком. Клик открывает нужную вкладку.
- [ ] **Выход.** Выйти из меню трея. В диспетчере задач не остаётся ни одного
      процесса `claude`.
- [ ] **Внешний вид.** Окно полупрозрачное, за ним просвечивает фон Windows
      (acrylic). Строка ввода Клода приглушена, наше поле — яркое, со свечением.

## Известные ограничения сборки

- [ ] Установщик **не подписан** — Windows SmartScreen покажет предупреждение
      при первом запуске. Так и задумано (ограничение 5.3).
- [ ] `signAndEditExecutable: false` в `electron-builder.yml`: распаковка
      кэша electron-builder требует прав на создание символических ссылок.
      Без них `Qclod.exe` не получает собственную иконку и метаданные
      (иконка установщика и ярлыков при этом правильная). Чтобы собрать
      полностью: включить **Режим разработчика** в параметрах Windows
      (Параметры → Конфиденциальность и защита → Для разработчиков) либо
      собрать из консоли с правами администратора, затем вернуть
      `signAndEditExecutable: true` и пересобрать.
