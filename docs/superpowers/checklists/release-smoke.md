# Релизный чек-лист Qclod

Автотесты гоняются только против подставного SDK — так они детерминированы, не
требуют аккаунта и не тратят токены. Этот список закрывает то, что они
принципиально проверить не могут: поведение **настоящего** Claude Code и вещи
уровня операционной системы.

Прогоняется один раз перед выпуском установщика.

```
npm run typecheck        # должно быть зелено
npm run test:unit        # должно быть зелено
npm run test:e2e         # должно быть зелено
npm run dist             # собирает dist/Qclod-<версия>-setup.exe и dist/Qclod.exe
QCLOD_PACKAGED_EXE=dist/win-unpacked/Qclod.exe npx playwright test packaged
```

Затем — один прогон против **настоящего** агента, автоматом:

```
node scripts/smoke-real-agent.mjs
```

Он открывает собранное приложение без подставного SDK, задаёт один вопрос и
проверяет, что ответ пришёл и панель заполнилась. Стоит доли цента и ловит то,
чего не видит ни один автотест: работает ли SDK внутри упакованного Electron.

Затем поставить установщик в чистую папку и пройти список руками.

## Против настоящего агента

Всё ниже — с настоящим `claude`, без `QCLOD_FAKE_SDK`.

- [ ] **Сессия поднимается.** Открыть папку с кодом, задать вопрос, получить
      ответ. В ленте одна реплика пользователя, не две.
- [ ] **Текст печатается на ходу.** Ответ появляется по мере печати, а не
      целиком в конце.
- [ ] **Карточки инструментов.** `Read`, `Edit`, `Bash` дают по одной строке с
      целью и итогом; клик раскрывает подробности.
- [ ] **Ошибка инструмента** показана красным и раскрыта сразу.
- [ ] **Размышления** сворачиваются в «думал N секунд».
- [ ] **Список задач** (`TodoWrite`) висит сверху и перезаписывается целиком.
- [ ] **Подагент** (`Task`) — карточка со вложенными вызовами внутри.
- [ ] **Прерывание.** Esc во время работы останавливает агента, черновик в поле
      остаётся на месте.

## Разрешения и режимы

- [ ] **Диалог разрешения.** Попросить что-то, требующее подтверждения;
      карточка появляется в ленте на месте будущего вызова.
- [ ] **«Разрешить всё такое»** — второй такой же вызов проходит без вопроса.
- [ ] **Правило видно и удаляется** в настройках; после удаления снова
      спрашивает.
- [ ] **В папке проекта ничего не появилось.** Проверить, что
      `.claude/settings.local.json` не создан и не изменён.
- [ ] **Режим плана.** Включить «план», дать задачу; агент показывает план,
      кнопка «Выполнять» переводит в «принимать правки» и работа продолжается.
      «Ещё обсудим» ничего не выполняет.
- [ ] **Shift+Tab** переключает режимы по кругу.
- [ ] **«Без проверок»** спрашивает подтверждение системным окном; отмена
      оставляет прежний режим.
- [ ] **Вопрос агента** (`AskUserQuestion`) показывает варианты; выбранный
      уходит сообщением и агент его понимает.

## Ввод и вложения

- [ ] **Скрепка** открывает выбор файлов; выбранное видно плашками, плашка
      снимается до отправки.
- [ ] **Ctrl+V с файлом, скопированным в проводнике** — файл прикрепляется.
      (В v1 не работало совсем.)
- [ ] **Ctrl+V со скриншотом** — картинка уходит вложением, агент её видит.
- [ ] **Перетаскивание** файлов в окно прикрепляет их.
- [ ] **Путь с пробелами и кириллицей** доходит одним файлом.
- [ ] **`@` открывает автодополнение** по файлам проекта; выбранный файл агент
      читает.
- [ ] **Ctrl+Z / Ctrl+Shift+Z, Ctrl+A/C/V/X** работают как в обычном поле.
- [ ] **На русской раскладке** Ctrl+V и Ctrl+Z работают так же.

## Команды, история, панель

- [ ] **`/` открывает палитру** с настоящим списком команд, включая
      пользовательские и плагинные.
- [ ] **`/compact`, `/model`, `/clear`** выполняются и видны в ленте.
- [ ] **`/remote-control`** помечена недоступной и не выбирается.
- [ ] **Компактизация** рисует разделитель с числом освобождённых токенов.
- [ ] **История (Ctrl+H)** показывает прошлые разговоры этой папки с датой и
      первой репликой; поиск фильтрует.
- [ ] **Открытие из истории** поднимает переписку в новой вкладке целиком.
- [ ] **Панель** показывает контекст с разбивкой, расход за сессию, оба лимита
      подписки с временем сброса, модель и MCP-серверы с состоянием.
- [ ] **Папка со своими хуками** — в панели видна строка «Настройки этой папки»
      с их числом и именами MCP-серверов.
- [ ] **Ctrl+\\** складывает панель, состояние переживает перезапуск.

## Вкладки и окно

- [ ] **Переключение вкладок мгновенное.** Никаких задержек и прыжков — ровно
      то, на что жаловались в v1.
- [ ] **Черновик и вложения** у каждой вкладки свои и переживают переключение.
- [ ] **Фоновая вкладка** не держит процесс агента, пока на неё не перешли.
- [ ] **Возобновление после перезапуска.** Закрыть приложение, открыть снова —
      вкладка продолжает ту же переписку.
- [ ] **Папка исчезла.** Переименовать папку вкладки, перезапустить: вкладка
      помечена, агент не поднимается, приложение работает.
- [ ] **Трей и глобальный хоткей** показывают и прячут окно.
- [ ] **Уведомление** приходит, когда агент закончил, а окно не в фокусе;
      клик по нему открывает нужную вкладку.
- [ ] **Закрытие последней вкладки** открывает новую, окно не остаётся пустым.

## Установка

- [ ] **Установщик** ставится без прав администратора, ярлыки создаются.
- [ ] **Портативный `Qclod.exe`** запускается из любой папки.
- [ ] **Первый запуск на машине без Qclod** находит `claude` в PATH; если нет —
      показывает понятную ошибку с подсказкой указать путь в настройках.
- [ ] **Неверный путь к агенту** в настройках даёт понятную ошибку, а не
      молчание.

Заполняется при выпуске.

| Дата | Версия | Кто | Итог |
| --- | --- | --- | --- |
| 2026-11-07 | 0.1.0 | автоматический прогон | `smoke-real-agent` — **пройден**: настоящий агент ответил из собранного приложения, модель и лимиты в панели есть. Ручной список ниже ещё не пройден. |

**Что нашёл первый же прогон смоука** (и что теперь починено):

- SDK — ESM-пакет, а главный процесс собирается в CommonJS, поэтому
  `import()` превращался в `require()` и падал с «require() of ES Module not
  supported». Все автотесты при этом были зелёными: они подставляют фикстуру и
  настоящий SDK не грузят вовсе. Починено `src/main/esm.ts`.
- Канал `files:index` не был зарегистрирован — автодополнение по `@` молча не
  работало.
