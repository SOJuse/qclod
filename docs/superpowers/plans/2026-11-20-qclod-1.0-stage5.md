# Qclod 1.0 — этап 5: голосовой ввод. План реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Человек держит Ctrl+Пробел (или жмёт кнопку микрофона) и говорит по-русски. Текст появляется по ходу речи: серым — незаконченная фраза, в поле — законченные фразы с пунктуацией и заглавными, английские термины поправлены словарём. Голос только вставляет, никогда не отправляет. Модели скачиваются и удаляются в настройках «Голос». Пока модели нет — остаётся Win+H.

**Architecture:**
- Распознавание — в `utilityProcess` (`out/main/voiceWorker.js`): `sherpa-onnx-node` 2.0.2 на CPU (GigaAM v3 e2e-RNNT int8 по умолчанию, Parakeet TDT 0.6B v3 int8 — по выбору) или `whisper-server.exe` из whisper.cpp b5454 с CUDA (Whisper large-v3-turbo, только NVIDIA). Все три — за одним интерфейсом `SpeechEngine`.
- Silero VAD режет речь на фразы. `LiveDecoder` пересчитывает незаконченную фразу каждые 0,7 с (адаптивно) и выдаёт `partial`; пауза 0,65 с даёт `final`. Модуль не знает ни Electron, ни sherpa — тестируется на фейках.
- Окно: `getUserMedia` → `AudioWorklet` → куски по 100 мс PCM 16 кГц моно → main (`voice:audio`, проверка в main) → процесс голоса. Обратно: события `voice:event` → магазин голоса в окне → серая строка в `Composer` и вставка в черновик вкладки, где начали.
- Модели — загрузки в `userData/models/<id>/`: докачка по Range, SHA-256, `.part` и атомарное переименование, зеркало — пре-релиз `voice-models-v1` в `SOJuse/qclod`.
- Тестовый путь: `FakeSpeechEngine` + энергетический VAD + фейковый микрофон Chromium из WAV — только под `__QCLOD_TEST_SEAMS__`.

**Tech Stack:** Electron 33 (`utilityProcess`, `session` permission handlers, `net.fetch`), React 18, zustand, TypeScript, vitest, Playwright; `sherpa-onnx-node` 2.0.2 (+ `sherpa-onnx-win-x64`), whisper.cpp b5454 `whisper-bin-win-cuda-12.4.0-x64.zip`.

**Spec:** `docs/superpowers/specs/2026-11-20-qclod-1.0-design.md`, этап 5 (5.1–5.3). ## Решения автора плана

1. **T-one не ставим.** Спек 5.1/5.2 называет T-one «лёгкой потоковой» и черновиком, если пересчёт не успевает. Координатор после замеров 06 (answers.md) оставил три модели: GigaAM, Whisper (CUDA), Parakeet. GigaAM укладывается в бюджет (префикс до 6 с — 0,23–0,48 с), а адаптивный интервал закрывает длинные фразы. T-one без пунктуации и латиницы — в итоговый текст не годится.
2. **Whisper — только на видеокарте NVIDIA, через `whisper-server.exe`** (готовый бинарник whisper.cpp b5454, проверен на этой машине), а не через sherpa: sherpa-onnx-node на Windows GPU не умеет (06 §4), Whisper на CPU — RTF 1,4–3,1. Сервер держит модель загруженной, говорим с ним по HTTP на `127.0.0.1` со случайным портом. Если сервер поднялся без CUDA — считаем это отказом (на CPU он бесполезен).
3. **Звук идёт через main, а не через `MessagePort` напрямую.** 10 кусков по 6,4 КБ в секунду — пустяк. Зато каждый кусок проверяет main (ограничение 4 спека), и не нужно переподключать порт при перезапуске процесса голоса.
4. **Серый текст — отдельной строкой внутри поля ввода, а не в самом `textarea`.** Часть текста в `textarea` нельзя покрасить. А переписывать текст под курсором, пока человек печатает, — значит драться с ним. Законченные фразы вставляются в черновик на место курсора.
5. **Клавиша — Ctrl+Пробел по физическому коду.** Удержание ≥ 400 мс — «держу и говорю», отпустил — стоп. Короткое нажатие — старт, следующее — стоп. Кнопка микрофона работает так же (G1). Работает только в окне (G10). Не срабатывает, пока открыт модальный слой. `Ctrl+Shift+Space` остаётся глобальной клавишей окна. Перенастройки нет (K7).
6. **Esc во время записи останавливает голос, а не агента.** Второй Esc — как раньше.
7. **Модель грузится при первом нажатии (около 3,4 с), а не при старте Qclod.** Звук, сказанный во время загрузки, копится в процессе голоса (до 30 с) и распознаётся после загрузки. Через 10 мин простоя процесс голоса закрывается — это единственный надёжный способ вернуть 0,3–0,9 ГБ памяти.
8. **Падение процесса голоса:** сообщение и перезапуск по следующему нажатию. Третье падение за 10 мин — голос выключен до перезапуска Qclod, работает Win+H.
9. **Отказ Whisper на видеокарте — только на эту сессию:** если GigaAM скачана, Qclod распознаёт ею и говорит об этом. Настройку не меняем: отказ драйвера бывает временным.
10. **Словарь в настройках хранится как `null` = «стандартный»**, пока человек его не правил. Иначе обновления стандартного списка не доходили бы до тех, у кого он уже сохранён. Запись словаря матчит целое слово без учёта регистра, ё = е, пробел и дефис внутри необязательны, плюс частые русские окончания («Клода» → «Claude»). Hotwords не делаем: с GigaAM их не проверяли (06 §3.6).
11. **Микрофон — системный по умолчанию, без выбора в настройках** (анти-цель A10).
12. **Зеркало — пре-релиз** `voice-models-v1` в `SOJuse/qclod`. Обычный релиз стал бы «последним» для `electron-updater` и сломал бы обновления друзей.
13. **Скачивается одна модель за раз.** Архив CUDA (zip) распаковывается системным `%SystemRoot%\System32\tar.exe` по абсолютному пути. Модели sherpa качаются пофайлово с Hugging Face: в Node нет bzip2.
14. **Разрешения окна:** обработчик сессии решает только `media` (только звук и только для нашего окна). Остальные разрешения ведут себя, как сейчас, — сужать их не задача этапа.
15. **Пунктуация и заглавные (G7) проверены у всех трёх моделей** по текстам замеров (`results/*.json`): GigaAM e2e-RNNT и Parakeet ставят их сами, Whisper тоже. Своего восстановления пунктуации не делаем. На стыке фраз только снимаем лишнюю точку после разреза на 11 с.
16. **Конфликт `onnxruntime.dll` из System32 заранее не обходим.** `uv_dlopen` грузит зависимости `.node` из его папки (так прототип и работал). Проверка — в собранном приложении в Windows Sandbox (задача 11). Если ошибка там проявится — стоп и Ruling координатора (запасной движок — `transcribe-cpp`, отчёт 03 §5.2), а не хак наугад.

Алгоритм `LiveDecoder` (06 §3):
1. Буфер фразы начинается в момент, когда `vad.speaking` стал `true`, плюс `preRollMs` звука до него (кольцевой буфер).
2. Пока фраза идёт: `partial`, когда с прошлого пересчёта набралось не меньше `max(partialEveryMs, slowFactor × время прошлого decode)` звука и нет декода «в полёте». Время декода меряется `now()`. Пропущенный пересчёт не копится: следующий берёт свежий буфер.
3. `vad.takeClosed() > 0` — финальное декодирование буфера. `final` с тем же `phrase`, затем `phrase += 1`. Если финал ждёт, пока идёт `partial`, он стоит первым в очереди.
4. Фраза длиннее `maxPhraseMs` — `final` с `cut: true`, новая фраза начинается без пре-ролла.
5. Фраза короче `minPhraseMs` — без `final`; если был `partial`, шлётся `final` с `text: ''`.
6. `partial`, пришедший после `final` своей фразы, выбрасывается.
